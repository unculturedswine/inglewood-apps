# inglewood-apps

Public admin pages (support, privacy policy) for apps, served by GitHub Pages at
https://unculturedswine.github.io/inglewood-apps/.

One folder per app: `index.html` is its support page, and `privacy.html` is its privacy policy.
The pages only. App code stays in each app's own private repo.

Magic Melodies' privacy page is maintained in that app's repo (`store/privacy.html`). Copy it
here when it changes.
